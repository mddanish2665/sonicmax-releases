# SonicMax — Downloads

SonicMax is an audio enhancer for Windows and Android (bass, clarity, spatial and limiter processing, with genre presets and headphone profiles). All audio is processed locally on your device.

## Download

Go to **[Releases](../../releases/latest)** and download:

| Platform | File |
|---|---|
| Windows 10/11 (64-bit) | `SonicMax-Setup-1.0.0.exe` |
| Android 8.0+ | `SonicMax-1.0.0-android.apk` |

### Windows
Run the setup file. If SmartScreen warns about an unknown publisher, click **More info → Run anyway**.

### Android
Open the APK on your phone and allow **Install unknown apps** for your browser or file manager when asked.

This repository contains only the released software. The source code is not public.
